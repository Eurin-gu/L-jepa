# 项目汇报：从 JEPA-CO2 到 Lagrangian-JEPA 的选题演进与实验结果总结

## 0. 一句话总结

> 旧实验已经表明 **JEPA 预训练在足迹仿真任务上有稳定的样本外泛化优势**，但标签仍是代理，不能作为真实物理结论。  
> 新方向把问题从“CO2 源归因”收敛为 **Lagrangian-JEPA 输送算子学习**，用真实 STILT/GenGHG 标签重新验证这一优势，并尝试冲击 CVPR。

---

## 1. 旧 JEPA-CO2 选题回顾

### 1.1 最初问题

- 数据：OCO-2/OCO-3 稀疏 XCO2、NO2、HRRR 风场、背景场
- 目标：温室气体源级归因、羽流概率、排放率后验
- 方法：Transport-Conditioned JEPA / 风场条件化 token 坐标

### 1.2 旧选题的合理部分

- 没有把稀疏 OCO-2 强行补成连续羽流图；
- 区分合成真值和真实事件；
- 没有把 NO2 当作 XCO2 真值；
- 提出了可证伪的零假设。

### 1.3 旧选题的问题

- 真实 OCO-2 缺少逐事件源真值；
- 任务可辨识性风险大；
- “Transport-JEPA” 容易退化成 `x - uT` 坐标预处理；
- 真实数据验证困难；
- CVPR 方法新颖性不足。

##

## 2. 旧实验结果：JEPA vs Scratch vs U-Net++

### 2.1 实验设定

- 数据：10 个 HRRR-lite 场，2021-07 训练，2021-10 测试
- 标签：`simple_lagrangian` 24h 后向轨迹足迹（代理，不是 STILT）
- 输入：20 通道气象 + 高斯羽流先验 + 距离特征
- 模型：
  - U-Net++（论文方法，scratch）
  - Plain U-Net（同架构 scratch）
  - JEPA 预训练 + 微调

### 2.2 样本外结果

| 模型 | Pearson r (all) | Pearson r (target>0) | RMSE | 质量误差 | 峰值距离 |
|---|---:|---:|---:|---:|---:|
| U-Net++（scratch） | 0.426 | 0.340 | 8.37e-05 | 11.2% | 14.9 |
| Plain U-Net（scratch） | 0.355 | 0.273 | 8.52e-05 | 11.9% | 16.1 |
| **JEPA** | **0.492** | **0.403** | **8.10e-05** | **5.2%** | **11.7** |

### 2.3 泛化差距

| 模型 | 样本内 r_pos | 样本外 r_pos | 差距 |
|---|---:|---:|---:|
| U-Net++ | 0.611 | 0.340 | 0.271 |
| Plain U-Net | 0.591 | 0.273 | 0.318 |
| JEPA | 0.567 | 0.403 | **0.164** |

### 2.4 解读

- JEPA 全面优于同架构 Scratch；
- JEPA 优于论文 U-Net++；
- 泛化差距缩小近一半；
- 说明 JEPA 预训练的主要收益是 **样本外泛化**，不是单纯拟合训练集。

## 3. Temporal-JEPA Pilot 结果

### 3.1 对比模型

- Scratch
- Random Transfer（随机迁移）
- Temporal JEPA

### 3.2 结果

| 模型 | pooled r_pos | casewise r_pos mean | 质量误差 | 质心距离 |
|---|---:|---:|---:|---:|
| Scratch | 0.164 | 0.123 | 37.9% | 38.3 |
| Random Transfer | 0.224 | 0.190 | 24.3% | 44.0 |
| **Temporal JEPA** | **0.257** | **0.246** | 29.7% | 42.8 |

### 3.3 配对检验

- Temporal JEPA vs Scratch：
  - r_pos 平均提升 `+0.123`
  - 95% CI `[0.103, 0.145]`
  - win rate `73.5%`
- Temporal JEPA vs Random Transfer：
  - r_pos 平均提升 `+0.056`
  - 95% CI `[0.033, 0.080]`
  - win rate `58.8%`

### 3.4 解读

- 相对 Scratch 统计显著；
- 相对 Random Transfer 也有提升，说明不是“随便迁移一个权重就有用”；
- 但 win rate 不是 100%，说明并非每个样本都赢。

## 3.5 Go/No-Go 源归因实验（`go_nogo/`）

### 实验题目

> 稀疏 CO2/NO2 观测 → 源级定位：在未见风场下，固定时窗回溯坐标这一归纳偏置是否优于原始坐标？

对比配置：

```text
scratch_euc / scratch_src
jepa_euc / jepa_src
mae_euc / mae_src
deepsets / CNN / U-Net
physics / prior_only / shuffled / fixed wind
```

### 合成完整矩阵结果（5 seeds，recall@4）

| 模型 | 平均 recall@4 |
|---|---:|
| physics（无先验物理标尺） | 0.335 |
| CNN (Euclidean) | 0.291 |
| U-Net (Euclidean) | 0.291 |
| scratch_euc | 0.276 |
| MAE (backtrack) | 0.271 |
| scratch_src | 0.268 |
| JEPA (backtrack) | 0.257 |
| JEPA (Euclidean) | 0.251 |
| MAE (Euclidean) | 0.244 |
| DeepSets (backtrack) | 0.158 |
| JEPA shuffled wind | 0.178 |
| JEPA fixed wind | 0.173 |

### 三连判定（全部 FAIL）

| 判定 | 比较 | 差值 | 结论 |
|---|---|---|---|
| (c) transport coord helps | scratch_src - scratch_euc | -0.0084 | ❌ FAIL |
| (b) JEPA beats scratch | jepa_euc - scratch_euc | -0.0246 | ❌ FAIL |
| (a) Transport-JEPA beats JEPA | jepa_src - jepa_euc | +0.0054 | ❌ FAIL（CI 含 0） |

### 分析

1. **回溯坐标本身没有稳定收益**：
   - scratch_src 并没有超过 scratch_euc；
   - 说明 `x - uT` 不能简单等同于“学会了输送物理”。

2. **JEPA 在源归因任务上没有超过 scratch**：
   - 普通 JEPA 反而低于 scratch；
   - 说明 JEPA 的收益依赖任务和数据，不能默认迁移到任何下游。

3. **物理标尺仍然是最强参照**：
   - 无先验物理 matched filter 达到 0.335，高于所有学习模型；
   - 说明当前学习模型没有充分利用观测信息。

4. **错配风/固定风负控制远低于正常回溯**：
   - shuffled/fixed wind 显著下降；
   - 说明风场信息确实有用，但“当前回溯坐标形式”没有带来可测量的学习增益。

5. **结论**：
   - 源归因路线在当前 OSSE 设定下 **Go/No-Go 未通过**；
   - 这支持转向 **输送算子学习**，而不是继续在源归因上投入大规模训练。

### Real-met（真实 HRRR OSSE）

- 当前 real-met 只有 5 个测试 snapshot、2 个日期；
- 不允许 formal inference；
- 修复后物理标尺约 0.29，学习模型仍在 0.12–0.13 附近；
- 说明真实气象/几何下任务更难，且学习模型尚未超过先验/物理参照。

## 4. 新方向：Lagrangian-JEPA 输送算子学习

### 4.1 为什么转向

| 维度 | 源归因 | 输送算子 |
|---|---|---|
| 训练标签 | 真实标签极少 | 模拟器可规模生成 |
| 评价真值 | 含糊、受先验影响 | 可直接对模拟器输出 |
| 背景干扰 | 很强 | 可以暂时隔离 |
| 科学闭环 | 较弱 | 清晰 |
| CVPR 风险 | 数据真实性 | 方法新颖性 |

### 4.2 核心任务

```text
输入：
    气象场 M(x,y,z,t)
    + receptor/source query q
    + 回溯时长、高度、边界层信息

输出：
    K(x,y,tau | M,q)
```

其中 `K` 是 source-receptor sensitivity / Lagrangian footprint / 条件 Green's function。

### 4.3 新方法定义

**Lagrangian-JEPA**：

> 沿后向空气轨迹组织 masked latent prediction，而不是在固定空间网格上随机 mask。

- 普通 JEPA：mask 空间块，预测 latent；
- Eulerian-JEPA：在固定坐标预测未来 latent；
- **Lagrangian-JEPA：沿轨迹预测上游/下游 latent**。

### 4.4 五臂实验设计

```text
train-mean shape（零参数基线）
Scratch
Met-MAE
Eulerian-JEPA
Lagrangian-JEPA
```

统一：

- 相同 encoder/decoder；
- 相同参数量；
- 相同监督数据；
- 相同训练预算；
- 多种子。

### 4.5 数据

优先使用 **GenGHG v1.0**：

- 40,000+ 个 STILT footprint；
- 2019–2025；
- 60 个全球城市热点；
- GFS 气象输入；
- 24h 后向输送。

### 4.6 跨域泛化

第一版至少验证：

- 跨区域：训练部分城市，测试完全留出城市；
- 跨季节：训练部分月份，测试独立季节。

第二期扩展：

- 跨分辨率；
- 跨模拟器/气象驱动。

## 5. 新旧方向对比

| 维度 | 旧 JEPA-CO2 源归因 | 新 Lagrangian-JEPA 输送算子 |
|---|---|---|
| 主任务 | 稀疏 XCO2 → 源归因 | 气象 + query → footprint / H |
| 标签 | 真实标签少、难验证 | STILT/GenGHG 可生成 |
| JEPA 作用 | 风场条件化 token | 轨迹感知 latent prediction |
| 可验证性 | 弱 | 强 |
| 科学闭环 | 弱 | 清晰 |
| CVPR 可能性 | 低 | 中高（需通用化） |
| 期刊落点 | RSE/TGRS/AMT | GMD/AMT/JAMES/CVPR |

---

## 7. 关键红线

- 真实 STILT 标签之前，所有结果只能叫 proxy/OSSE；
- 不能把 `x - uT` 包装成 Lagrangian 学习；
- 五臂必须共享初始化、数据和训练协议；
- train-mean 零参数基线不过线，就不能声称方法有效；
- 测试日期少于 5 个时禁止 formal inference。

---

## 8. 结论

> 旧实验支持“JEPA 预训练对足迹仿真泛化有帮助”这一假设；  
> 新 Lagrangian-JEPA 方向把这一假设放到真实 STILT 标签和跨域泛化上检验；  
> 如果跨区域/跨季节结果稳定，有潜力成为 CVPR 工作；  
> 如果跨域增益不明显，仍然可以作为 GMD/AMT 方法学论文。
