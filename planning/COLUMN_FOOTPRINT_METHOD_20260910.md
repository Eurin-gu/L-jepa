## 1. 背景：FootNet v3 的双模型架构（对标基准更正）

2026-09-10 学习 FootNet 论文时发现，此前对 FootNet 的理解不完整。**FootNet v3（ACP 2026,
Dadheech & Turner）是两个独立模型，而非单一模型**：

| 模型 | 训练真值 | 服务对象 |
|---|---|---|
| **Surface FootNet** | **STILT** | 地面站点（BEACO₂N、INFLUX） |
| **Column FootNet** | **X-STILT** | 柱平均观测（TROPOMI、OCO-2/3） |

论文原文：
> "It **comprises separate models for surface and column-averaged footprints** and is trained
> using **STILT and X-STILT outputs, respectively**."
> "Each receptor was simulated using **STILT for surface footprints and X-STILT for
> column-averaged footprints**... trajectories were simulated **backward in time for 72 h**"

其他关键配置：50 万样本、CONUS、HRRR 3km→1km、两模型空间时间**共址**（matched training set）、
Column 模型 mass penalty α=0（无益）。

**对本项目的含义**：我们受体来自 OCO-2（柱观测），严格对标的应是 **Column FootNet ← X-STILT**，
而非 Surface 模型。一期已冻结的 5m 地表足迹对应 Surface 模型。

## 2. 技术验证：多高度释放与高层失灵的物理机制

### 2.1 引擎支持性测试

`stilt_cli.r` L67-75 接受逗号分隔的 `r_zagl`（设计上支持 slant column release）：

```r
if (grepl(',', args$r_zagl, fixed=T)) {
    zagl_parts <- strsplit(args$r_zagl, ',', fixed=T)[[1]]
    r_zagl <- lapply(zagl_parts, function(x) as.numeric(x))
}
```

**实测结果（2017-10-23, po_valley_italy, p250, 24h 后向）**：

| 配置 | 结果 | foot_sum |
|---|---|---|
| `r_zagl=5,100,300,800,1500,3000,6000`（一次 7 高度） | ❌ 无 foot.nc | 0（foot 列全零） |
| 单高度 100 m | ✅ | 0.7209 |
| 单高度 800 m | ✅ | 0.3401 |
| 单高度 3000 m | ❌ | — |
| 单高度 6000 m | ❌ | — |

**多高度失败原因**：CONTROL 正确写入 7 个受体，HYSPLIT 跑完 100%，但 `traj.rds` 的
`foot` 列 sum=0/nonzero=0，HYSPLIT MESSAGE 中每个粒子质量为 `0.00000000` →
**该引擎的多受体质量分配失败**。因此必须**每个高度单独一次运行**。

### 2.2 高层 foot=0 的物理机制（核心发现）

读取 `traj.rds` 对比粒子高度与 PBL 高度：

| 释放高度 | 粒子高度范围 | PBL 高度范围 | **PBL 内时间占比** | foot |
|---|---|---|---|---|
| 3000 m | 1338–4578 m | 250–1885 m | **0 %** | **0** |
| 6000 m | 4199–8954 m | 250–1962 m | **0 %** | **0** |
| 800 m | 0–4559 m | — | 18.2 % | 86.9 |

**机制**：STILT 的 `foot` = 粒子在 PBL 内（与地表接触）的时间累加。从 3000 m 释放的粒子
在 24 h 后向窗口内最低只降到 1338 m，**始终位于 PBL 顶（1885 m）之上**，从未接触地表 → foot≡0。

**排除域大小因素**：将域从 ±256 km 扩大到 ±500 km 后重跑 3000/6000 m，**仍然失败** →
证明与域大小无关，是 PBL 接触问题。

**这正是 FootNet 使用 72 h 后向的原因**：高层空气需要更长时间才能下沉/混合进 PBL。

### 2.3 STILT 对零足迹的处理（影响数据管线）

`run_stilt.r` / `simulation_step.r` L375：

```r
if (is.null(foot)) {
  msg <- 'No non-zero footprint values found within the footprint domain.'
  warning(msg); return()          # ← 直接返回，不写 foot.nc
}
```

**所以 foot≡0 的高度不产出文件**。实测验证：20150211 的 30/30 高层 sim 均带此警告 →
**缺失 = 物理零，不是运行失败**。合成时必须按零层处理（见 §4.2）。

### 3.3 高层足迹强度的季节差异（关键定量结果）

各日期不同高度的 foot_sum 中位（每日期 6 受体抽样）：

| 日期 | 5m | 100m | 300m | 800m | 1500m | 高层存在率 |
|---|---|---|---|---|---|---|
| 20150211（冬） | 1.34 | 0.936 | 0.681 | **—** | **—** | 1/240 |
| 20160115（冬） | 1.80 | 1.38 | 1.22 | **0.027** | **0.0027** | 201/240 |
| 20160221（冬） | 1.27 | 1.07 | 1.03 | 0.867 | **0.0073** | 201/240 |
| 20160714（夏） | 1.17 | 0.828 | 0.643 | 0.447 | 0.359 | 240/240 |
| 20160909（夏） | 1.89 | 1.55 | 1.49 | 1.14 | **0.899** | 240/240 |
| 20150721（夏） | 1.41 | 1.26 | 1.20 | 1.09 | 0.964 | 240/240 |
| 20150813（夏） | 0.687 | 0.481 | 0.496 | 0.462 | 0.557 | 240/240 |

**结论**：同一高度（1500 m）在不同季节的 foot_sum 相差 **300 倍以上**（0.0027 vs 0.964）。
这是 PBL 季节变化的忠实体现：

- **冬季**：PBL 低（可 <300 m）→ 800/1500 m 在 PBL 外 → foot≈0 → **柱足迹≈地表足迹**
- **夏季**：PBL 高（>1500 m）→ 各层均在 PBL 内 → **柱足迹显著不同于地表足迹**

→ **柱足迹与地表足迹的差异是季节依赖的**，这是一条可写进论文的定量结论。

## 4. 方法论

### 4.1 高度集合与权重

**高度集合**：`{5, 100, 300, 800, 1500}` m
- 全部 ≤1500 m 已验证在 24 h 后向 + ±256 km 域内可行
- 覆盖 PBL 及顶部（实测 PBL 顶 250–1962 m）

**气压厚度权重**（指数大气近似，标高 8000 m）：

```python
p(z) = 1013.25 * exp(-z / 8000)                      # hPa
b    = [0, 52.5, 200, 550, 1150, 1850]               # 相邻高度中点作层边界
w_z  = (p(b_lo) - p(b_hi)) / Σ                        # 归一化
# => [0.0317, 0.0879, 0.2022, 0.3267, 0.3515]
```

**合成公式**：

```
F_col = Σ_z w_z · F_z / Σ(F_z)        # 每层先按自身质量归一化，再加权
```

### 4.2 物理零层的处理（v2 修正）

初版脚本要求 5 层齐全才合成 → **会丢弃 25% 的样本**（20150211 全部 120 个受体丢失）。
修正后：**缺失层按零处理并保留受体**（依据 §2.3 的实测验证）。

结果：样本保留率从 75% → **100%**（787 vs 591）。

## 6. 局限与风险

| # | 风险 | 说明 |
|---|---|---|
| R1 | **非完整柱** | 仅覆盖 5–1500 m，缺自由对流层贡献 |
| R2 | **权重为近似** | 指数大气，未用 ERA5 实际气压剖面 |
| R3 | **层边界主观** | 相邻高度中点，非标准分层 |
| R4 | **物理结论基于单日** | 高层 foot=0 的 PBL 判据主要在冬季/单日验证 |
| R5 | **24 h vs 72 h** | 后向窗口短，可能系统性低估远距离源贡献 |
| R6 | **固定高度的季节缺陷** | 冬季高层全零，固定高度集合在不同季节代表不同物理位置 |
| R7 | **磁盘** | 单 sim 6 MB × 6600 ≈ 40 GB；WSL vhdx 空洞 64 GB，余量有限 |
| R8 | **无断点续跑** | run_batch 未传 --resume，中断会重复计算 |
| R9 | **标签定义分叉** | 已有 5m 数据与柱足迹并存，须以 tag 严格区分 |
