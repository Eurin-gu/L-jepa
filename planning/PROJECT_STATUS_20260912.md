# 项目状态总览（截至 2026-09-12）

## 一、项目目标与核心问题

**要学的东西**：受体的"足迹"（footprint）——即某观测点测到的浓度，受上游何处地表通量影响的敏感性核。

形式化：
```
y = H x + b
  y: 观测浓度  x: 地表通量  H: 源-受体关系(=足迹)  b: 背景
```

**本项目的核心问题**：用深度学习**代替**物理传输模型（STILT/X-STILT）计算足迹，
并检验"**轨迹感知的自监督预训练（Lagrangian-JEPA）能否改进这个模拟器**"。

**对标基准**：FootNet v3（ACP 2026, UW）——见 §4.1。

## 二、数据集构建（schema v5）

### 2.1 单个样本的定义

每个**受体**（时间+经纬度+高度）产生一个样本：

| | 内容 | 形状 |
|---|---|---|
| **输入 x** | 20 通道 | (20, 128, 128) |
| **标签 y** | STILT 足迹（物理单位） | (128, 128) |

**x 的 20 个通道构成**：

```
ch 0      : 受体脉冲（中心像素=1，标记"我在哪"）
ch 1-16   : 4 个回看时刻 [0, 6, 12, 18 h] × 4 变量 [U10M, V10M, PBLH, PRSS]
ch 17-18  : 局部 x/y 坐标（相对半域，归一化）
ch 19     : 半径（到受体的归一距离）
```

**空间网格**：以受体为中心，128×128 @ **4 km** → 覆盖 ±256 km
（注意：FootNet 用 1 km / 400 km，我们粗 4 倍）

**为什么 4 个回看时刻**：捕捉气象场的演变（FootNet v1 只用 2 个时刻，v3 用 4 个：
0/6/12/24h；我们用 0/6/12/18h）。

### 2.2 构建流水线

```
① 受体选择 (make_receptors.py)
   OCO-2 卫星过境点 → QC(flag==0, 350<XCO2<450ppm) → maximin 选 120 个/日
   ↓
② STILT 模拟 (run_batch.py → stilt_cli.r → hycs_std)
   每受体独立一次后向轨迹模拟，输出 <sim>_foot.nc
   ↓
③ 特征提取 (assemble.py)
   从气象 GRIB 读 4 回看时刻的 4 变量 → 双线性插值到受体中心网格
   ↓
④ 标签重采样
   <sim>_foot.nc → 双线性重采样到 128×128 物理网格
   （覆盖率门槛：足迹须覆盖窗口 ≥80%，否则丢弃）
   ↓
⑤ 产出
   x.npy (N,20,128,128) + y.npy (N,128,128) + meta.json(含 contract 指纹)
```

**审计机制**：
- `contract_fingerprint`：schema 全部超参的哈希（网格/回看/归一化/门槛…）
- `source_fingerprint`：构建代码目录的哈希
- 加载时校验指纹，不匹配拒绝加载

### 2.3 关键约束（铁律）

| 约束 | 含义 |
|---|---|
| **特征与标签同源** | 跑 STILT 用的气象 = 提取特征用的气象（不能 HRRR 标签配 ERA5 特征） |
| **日期块切分** | train/val/test 按**日期**切，禁止按受体随机切（见 §5.2） |
| **独立单元 = 日期** | 统计推断按日期聚类，≥20 独立测试日才下正式结论 |

### 4.3 因果审计实验（2026-09-08）——**No-Go，但结论已更正**

**设计**：7 臂 × 3 seeds，val_date=20160428（n_val=120）

| 臂 | 含义 |
|---|---|
| scratch | 随机初始化基线 |
| met_mae | 随机块掩码预训练 |
| met_tubular | 随机朝向管掩码 |
| **lj_true** | 真入流轨迹掩码 |
| lj_reverse (F1) | 反向风 −u,−v |
| lj_perp (F2) | 垂直风 −v,u |
| lj_rand (F3) | 随机固定朝向 |

**原始结果**（date-macro Pearson r / relRMSE）：

```
scratch      r=+0.1194±0.1289   relRMSE=0.019
met_mae      r=+0.1905±0.2238   relRMSE=0.018
met_tubular  r=+0.0510±0.0407   relRMSE=0.019
lj_true      r=+0.0952±0.0577   relRMSE=0.019
lj_reverse   r=+0.1574±0.1422   relRMSE=0.019
lj_perp      r=+0.0712±0.0237   relRMSE=0.019
lj_rand      r=+0.1460±0.1667   relRMSE=0.020
配对 t 检验全部 p>0.55
```

**最初判定**："No-Go——掩码沿真实入流无效"

**⚠️ 该判定已被更正**（`CAUSALITY_AUDIT_ERRATUM_20260908.md`）：
发现 7 个错误 →
- E1 统计功效不足（**1 个 val 日期 + 3 seeds**，臂间差 < seed 波动）
- E2/E3 未在良性收敛区评测（val 从 ep8 起上升）
- E4 Pearson 被 93.6% 零像素稀释
- E5 **`relRMSE` 是误命名**（实为全像素 raw_rmse，无分母、未去零）
- E6 单日期无法外推
- E7 训练预算仅 40 epoch（监督）/ 25（预训练），均欠训

**更正后结论**："欠动力 pilot **未检出信号**"，**不支持也不否定** L-JEPA。

### 5.2 样本非独立性（受体高度聚集）

**受体间距实测**：

| 区域 | 同日最近邻距离 |
|---|---|
| po_valley | 1.0 / 1.6 / 3.0 km（min/med/max） |
| north_china | 0.2 / 0.8 / 14.8 km |
| so_cal | 1.4 / 2.5 / 7.5 km |

足迹网格 4 km → **相邻受体常在同一像素内**。

**足迹相似度**：

| 比较 | Pearson r |
|---|---|
| 同日内两两 | **0.932 – 0.990** |
| 跨日 | **0.729** |

**结论**：**有效样本量 = 日期数，不是受体数**。这是 pre-registration 冻结
"日期块切分"的依据，也是 FootNet 作者承认的同类问题。




- **冬季** PBL 低 → 高层零贡献 → **柱足迹 ≈ 地表足迹**
- **夏季** PBL 高 → 高层贡献显著 → **柱足迹明显不同于地表足迹**

FootNet 论文中明确提到的局限性和不足主要有以下几个方面：
1. 训练数据依赖物理模型，继承了其偏差
FootNet 的训练标签（y.npy）全部来自 STILT/X-STILT 物理模型的模拟结果。这意味着：
FootNet 无法超越其训练数据的精度上限——如果 STILT 本身在某些条件下存在系统性偏差（如复杂地形、极端天气下的粒子追踪误差），FootNet 也会继承这些偏差。
模型本质上是在"模仿"物理模型，而不是独立地从物理定律出发进行推理。
2. 泛化性存在边界
虽然论文展示了 FootNet 在未见过的区域（out-of-sample）也能表现良好，但训练数据仅覆盖了美国本土（CONUS）范围内的 50 万个随机受体点。论文承认：
对于训练区域之外的地理环境（如高纬度极地地区、热带雨林、复杂山地地形等），模型的泛化能力尚未得到充分验证。
不同地区的大气环流特征、地表覆盖类型差异很大，模型在这些区域的表现可能下降。
3. 物理可解释性较弱（黑箱问题）
尽管论文通过特征重要性分析（Permute-and-Predict）证明了模型学到的驱动因素与物理规律一致，但：
FootNet 本质上是一个深度学习模型，其内部决策过程仍然是不可完全解释的。
当模型给出异常结果时（如某个区域的足迹分布不合理），很难像物理模型那样追溯到具体的物理原因（如某个风场的误差）。
4. 对输入气象数据质量的依赖
FootNet 的输入完全依赖 HRRR 气象再分析数据。论文指出：
如果气象驱动数据本身存在误差（如风速、风向不准），FootNet 的足迹预测也会随之出错。
模型无法自我纠正输入数据中的错误，而物理模型在某些情况下可以通过粒子轨迹的自洽性来部分抵消输入误差。
5. 模拟时长固定为 72 小时
论文中 STILT 和 X-STILT 的模拟时长统一设为 72 小时（或粒子离开模拟区域）。这个选择虽然是领域惯例，但也意味着：
对于超长距离传输的场景（如跨洲传输），72 小时可能不足以捕捉完整的来源信息。
模型本身也继承了这一时间窗口的限制。
